## Project vision

DOJ's long-term ambition is to develop a connected digital ecosystem for global jewellery and valuable decorative-goods commerce. The planned direction includes merchant onboarding, structured product information, evidence-based provenance and verification workflows, marketplace discovery, order management, and integrations with appropriately authorised payment and logistics providers.

## Website features

The website is a static, responsive HTML project with no build step. It includes:
- English-only project website and whitepaper
- Project vision and ecosystem pillars
- BNB Smart Chain token information read from public JSON-RPC
- PancakeSwap routes with the official DOJ contract pre-filled
- Wallet connection, DOJ balance lookup and wallet_watchAsset support
- Proposed tokenomics clearly marked as illustrative and unconfirmed
- A 24-month roadmap from November 2026 to October 2028, targeting a controlled public release in H1 2028 subject to legal, technical and operational readiness
- Project contact, community links and risk disclosures
