## Project vision

DOJ's long-term vision is a connected digital ecosystem for global jewellery and valuable decorative-goods commerce. The planned direction includes merchant onboarding, structured product information, evidence-based verification workflows, online marketplace tools and integrations with appropriate payment and logistics providers.

## Current website scope

This is a static, responsive GitHub Pages website. No build step or paid hosting is required.

The site currently provides:
- English-only project introduction and ecosystem overview.
- Official token and contract references.
- Direct PancakeSwap routes with the DOJ contract pre-filled.
- Wallet connection, DOJ balance lookup and wallet-watch support.
- A clearly labelled illustrative tokenomics proposal.
- A 24-month project roadmap from November 2026 through October 2028.
- A concise project overview / whitepaper.
- Separate email enquiry paths for potential merchants, buyers and strategic partners.

The enquiry links open a pre-filled email draft to the official project address. They do not store or submit data to a website backend.
