Official website and public information hub for DOJ COIN (DOJ), a BEP-20 token on BNB Smart Chain.

## Website

The website is a static, responsive HTML page and is designed to run on GitHub Pages without a build step or paid hosting. It includes:
- Project vision and ecosystem pillars
- Token details read from BNB Smart Chain using public JSON-RPC calls
- Market-data lookup through the DexScreener public API
- PancakeSwap links with the DOJ contract pre-filled
- Wallet connection, DOJ balance lookup and wallet_watchAsset support
- Proposed tokenomics clearly marked as illustrative and unconfirmed
- Roadmap, community links and risk disclosures

## Important disclosures

The tokenomics percentages displayed on the website are an illustrative proposal only. They are not a representation of actual wallet balances, token distribution, vesting, liquidity locks or on-chain allocations. The marketplace, verification and cross-border payment features are project vision items and should not be described as live services until they are actually developed and launched.

## Deployment

GitHub Pages is configured for this repository. Updates to `index.html` on the published branch are served by GitHub Pages automatically after deployment completes. No package installation or build command is required.
